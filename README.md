## 내 도메인

**자연어처리(NLP)**

사람이 쓴 글에서 의미와 감정을 읽어내는 과정이 재미있어서 이 분야를 선택했습니다.
요즘은 한국어 텍스트 분류와 요약 모델을 중심으로 공부하고 있습니다.

- 관심 키워드: 텍스트 분류, 감정 분석, 문서 요약, LLM 파인튜닝
- 주로 쓰는 도구: Python, PyTorch, Hugging Face

## 이 과정에서 만들고 싶은 것

1. **한국어 리뷰 감정 분석기**
   쇼핑몰 리뷰를 긍정과 부정으로 분류하고, 어떤 표현이 판단에 영향을 줬는지 함께 보여주는 모델을 만들고 싶습니다.

2. **회의록 자동 요약 서비스**
   긴 회의 녹취록을 넣으면 핵심 논의와 결정사항, 할 일을 정리해주는 웹 서비스를 목표로 하고 있습니다.

3. **나만의 학습 기록 챗봇**
   공부하며 남긴 노트를 검색해서 질문에 답해주는 RAG 기반 챗봇을 만들어보고 싶습니다.
